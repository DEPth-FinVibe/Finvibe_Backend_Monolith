# 종목 캔들 조회 신뢰성 개선 Decisions

## D1. KIS 전체 실패 또는 비정상 빈 응답 정책

### 검토한 선택지

1. 실제 캐시가 있으면 캐시를 반환하고, 없으면 명시적 503을 반환한다.
2. 캐시 유무와 무관하게 항상 503을 반환한다.
3. 실패를 빈 배열로 반환한다.

### 결정

- 선택: 1번
- 결정자: 사용자
- 결정일: 2026-08-21

### 선택 이유

- KIS의 부분 장애를 차트 전체 장애로 확대하지 않고 이미 확보된 실제 캔들을 계속 제공한다.
- 정상적인 데이터 없음과 외부 장애를 빈 배열 하나로 숨기지 않는다.
- 반환 가능한 데이터가 없을 때는 의도된 503으로 구분해 일반 500 노출을 막는다.

### 감수한 트레이드오프

- fallback으로 반환하는 캐시가 요청 구간 전체를 포함하지 않거나 최신성이 낮을 수 있다.
- 기존 배열 응답 계약에는 데이터 완전성 메타데이터가 없으므로 운영 로그와 메트릭으로 fallback을 구분해야 한다.

### 구현 의존성

- 일부 KIS 호출만 성공한 경우 새 데이터를 포함할지는 D2에 의존한다.
- 외부에 노출할 503 오류 코드 식별자는 D5에 의존한다.
